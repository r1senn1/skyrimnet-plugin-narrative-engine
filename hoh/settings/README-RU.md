# NarrativeEngine HoH - Settings 0.8.0

Мод MO2 только с настройками для **NarrativeEngine v0.8.0**: один файл `SKSE/Plugins/NarrativeEngine.ini`. Это
файл из 0.8.0 без изменений, кроме значений ниже (каждое помечено комментарием `; HoH:`). Всё остальное, включая
новый раздел `[Plots]`, — по умолчанию 0.8.0. Без DLL, ESP и промптов; безопасно для текущего сейва.

| Ключ | 0.8.0 | HoH | Почему (по двум чистым сессиям 0.8.0, 26–27.10.2026) |
| ---- | ----- | --- | ---------------------------------------------------- |
| `[Director] iAdvanceThresholdRisingAction` | 80 | **65** | В 96 оценках напряжение в RisingAction в среднем ~21, максимум 65 дважды (засада самого NarrativeEngine и интимная сцена); 80 не достигалось ни разу, поэтому история 3,8 ч стояла в RisingAction и каждое событие требовало всё большего роста. Важно: это даёт циклу двигаться, но не добавляет спокойных событий — Climax и FallingAction (единственные фазы «снижения») покидаются на следующей проверке, потому что оценка сразу падает до 10–20, так что события остаются в основном «на рост». |
| `[BeatSystem] iBeatCooldownSeconds` | 120 | **900** | Дважды визит приходил через 7 минут после засады. Считается только активная игра (не пауза, бой или диалог), с конца предыдущего события. 15 минут убирают такие пары; обычный темп (событие раз в ~30–45 мин, ограничен доступными NPC) не меняется. |
| `[Beats] iLetterContentMaxWords` | 150 | **260** | Раньше письма на 151–223 слова выбрасывались целиком. |
| `[Beats] sBlacklistedSenders` | пусто | **`Delphine3DNPC; Sven3DNPC; Delphine; Sven`** | EditorID срабатывают только с DLL EditorID Fix (для 0.8.0 её пока нет), поэтому добавлены имена. |

**Размер контекста (добавлено 27.10.2026)** — больше истории для Директора и писателей, чтобы они видели, кто уже
писал или приходил и что уже было сказано:

| Ключ | 0.8.0 | HoH |
| ---- | ----- | --- |
| `iActionSelectEventRenderCap` | 10 | **30** (10 событий покрывали лишь ~24 мин разговора) |
| `iActionSelectLetterMemoryRenderCap` / `iActionSelectVisitMemoryRenderCap` | 6 | **10** |
| `iLetterComposeMemoryRenderCap` / `iVisitComposeMemoryRenderCap` | 6 | **10** |
| `iLetterComposeDialogueRenderCap` / `iVisitComposeDialogueRenderCap` | 25 | **50** |
| `iVisitConclusionPollRecentLinesRenderCap` | 8 | **17** |

Цена: промпты немного длиннее (больше входных токенов на вызов).

Заменяет `[NoDelete]NarrativeEngine HoH - Settings` (для 0.7.x, с лишними изменениями, которые данные не подтвердили).

## Установка (игра закрыта)

1. Включи мод и поставь **ниже** `[NoDelete]NarrativeEngine-v0.8.0` (выше приоритет), чтобы его INI выигрывал.
2. Старый `[NoDelete]NarrativeEngine HoH - Settings` оставь **выключенным**.
3. `overwrite\MCM\Settings\NarrativeEngine.ini` (изменения из дашборда/MCM) всё равно перекрывает этот файл. Сейчас
   там только Shift для горячей клавиши дашборда; всё, что меняешь во вкладке Settings дашборда, попадает туда.

## Подстройка

Слишком тихо: `iBeatCooldownSeconds=600`. Слишком часто: увеличь. История всё ещё застревает в RisingAction: порог 60.

## Откат

Выключи мод — NarrativeEngine вернётся к своему INI из 0.8.0.
